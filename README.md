# Aigentic Sales Call Cockpit

Internal sales-call navigation and note-taking tool for Aigentic Campaign.

## Included

- `index.html` — master live-call guide with per-question notes, local autosave, export and reset
- `mind-map.html` — compartmentalised sales-process mind map
- `vercel.json` — static deployment and security headers

## Notes and privacy

Prospect notes are stored only in the browser's local storage. They are not written to this repository or sent to a server. Export the call notes after each call and transfer the required information to the approved CRM record.

## Use

Open `index.html` locally or deploy the repository as a static Vercel project. The mind map is available at `/mind-map.html`.
